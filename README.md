# Simple Page Replacement Algorithm Simulator

## Operating Systems Mini Project

A polished beginner-friendly web simulator for demonstrating page replacement in Operating Systems.

### Algorithms
1. FIFO (First-In, First-Out)
2. Optimal Page Replacement

### Technologies
- HTML
- CSS
- Vanilla JavaScript

No React, Node.js, database, API, or external JavaScript library is required.

### How to run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html`.
3. Enter a page reference string.
4. Enter the number of page frames.
5. Run FIFO, Optimal, or Compare Both.

### Sample input
Reference string:
`7 0 1 2 0 3 0 4 2 3 0 3`

Frames:
`3`

### Project objective
To visualize page replacement decisions, page hits, page faults, and the difference between FIFO and Optimal replacement.
